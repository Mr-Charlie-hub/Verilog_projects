# Digital Design and Verification Projects

This repository contains a collection of RTL design and SystemVerilog verification projects developed as part of my learning and hands-on experience in VLSI Design and Verification.

## Projects

### CDC (Clock Domain Crossing)

Implementation and analysis of Clock Domain Crossing techniques used for reliable data transfer between different clock domains.

### FIFO

Parameterized FIFO design implemented in Verilog, including read/write control logic, status flags, and validation through simulation.

### PWM (Pulse Width Modulation)

Configurable PWM generator design used for duty-cycle control applications in digital systems.

### SRAM Parameterized

Parameterized SRAM model supporting configurable memory depth and width for RTL-level simulation and design exploration.

### Vending Machine

Finite State Machine (FSM) based vending machine controller implemented in Verilog.

### Verification

This directory contains SystemVerilog-based verification projects.

#### FIFO Verification (FIFO_VER_1)

Comprehensive SystemVerilog verification environment for FIFO design including:

* Transaction generation
* Driver and monitor components
* Scoreboard-based checking
* Functional verification using assertions and testcases
* Coverage-oriented verification methodology

#### Flip-Flop Verification (FLOP)

SystemVerilog verification environment for validating flip-flop functionality under different operating conditions and reset scenarios.
